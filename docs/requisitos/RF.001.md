# Cadrastro de seções por gênero dos livros 
**COMO** Bibliotecário(a) Chefe,
**QUERO** cadastrar uma nova seção de livros por gênero
**PARA** que eu possa organizar os exemplares de forma categorizada e manter o controle da capacidade física das estantes no sistema.

**Critérios de Aceitação:**
- Identificação Única: Deve ser possível informar o nome do gênero (ex: Ficção Científica, Biografias) ou um código de identificação da seção.
- Prevenção de Duplicidade: O sistema deve impedir o cadastro de seções com nomes ou gêneros já existentes.
- Localização: Deve ser possível informar em qual corredor ou andar a seção está localizada.
